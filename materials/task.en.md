# MobiCar case brief

[↩ Project](../README.md)

Reconstructed from the supplied task description. MobiCar is a service for hourly and daily car rental through a mobile app. The assigned role is product analyst intern.

## Funnel

1. Install the app.
2. Register.
3. Search for a nearby car.
4. Book a car and start a ride.

The dataset also includes a separate car-view stage.

## Case context

- Conversion from the first app visit to the first ride fell by 15% over the last two months.
- Installations grew by 10%.
- The share of registered users returning after seven days did not change.
- There were no major releases apart from changes to car search.
- App store reviews did not deteriorate.

These figures are supplied in the brief. The table does not contain all the information needed to verify them. First-visit-to-first-ride conversion and installation-to-first-ride conversion use different starting events.

## Task

Analyze eight weeks of data and create one chart that shows the conversion decline, identifies the problematic funnel stage and visually highlights the main issue.

Add a short explanation of the problem, the stage with the main losses, hypotheses for improving conversion and further checks.

## Submission format

One document containing the chart and a brief explanation, no more than one page. Accepted formats: PNG, JPG, PDF or a cloud link.
